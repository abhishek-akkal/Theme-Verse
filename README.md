# 🎨 ThemeVerse

ThemeVerse is a modern React + Tailwind CSS project that allows users to switch between multiple beautiful themes in real time. The project focuses on clean UI design, responsive layouts, reusable components, and dynamic theme management using React state.

---

## 🌐 Live Demo

🔗 https://theme-verse-1x33.vercel.app/

---

## ✨ Features

- 🌞 Light Theme
- 🌙 Dark Theme
- 💧 Blue Theme
- ✨ Purple Theme
- ⚡ Real-time theme switching
- 🎯 Clean and modern UI
- 🔄 Component-based architecture
- 🚀 Built with React and Tailwind CSS

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/abhishek-akkal/Theme-Verse
```

### Navigate into project folder

```bash
cd ThemeVerse
```

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```

Open:

```bash
http://localhost:5173
```
